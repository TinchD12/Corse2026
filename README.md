# Córcega 2026 — V3 Premium

Mini-guide familial en espagnol, optimisé mobile.

## Publication GitHub Pages
1. Crée un dépôt GitHub public.
2. Dépose `index.html` et `README.md` à la racine.
3. Settings → Pages.
4. Source : Deploy from a branch.
5. Branch : `main` et dossier `/ (root)`.
6. Save.

## Technique
- Site statique, aucun build.
- Carte : MapLibre GL JS + OpenFreeMap.
- Photos : Wikimedia Commons (chargées depuis leurs URLs publiques).
- Favoris : stockés localement sur le téléphone via localStorage.
